使用方法

入口为 index.html，设计支持双击离线打开，也可由本地 HTTP 服务打开。单击关联节点后使用“进入内部架构”，双击直接下钻。左侧提供全部 13 张图、21 项契约和预算页面。单个图可以独立打开、切换主题和导出。

门户用 srcdoc 同源嵌入处理 file:// iframe 隔离；不改浏览器安全设置。portal-data.js 保存独立图的字节副本，只在嵌入时添加 embed 属性；独立图原件和交付哈希不变。工程台账数据内嵌页面，不依赖离线 fetch。官方文档链接需要联网。

维护入口

  • source/：13 份 Archify JSON；修改后按 diagram_type 执行 validate、deliver、visual-check。
  • standalone/：通过交付检查的 HTML，以及绑定该 HTML 哈希的浏览器回执、截图与联系表。
  • engineering/contracts.json：机器可读契约；contracts.html 内嵌同一份数据，更新时须同步生成。
  • engineering/review.html：审查映射及可重算带宽预算；数值为示例而非实测。
  • validation/：本次制品、浏览器、门户与语义检查记录。不会沿用旧版“全部通过”结论。
  • maintenance/：维护脚本：node maintenance/rebuild.mjs 默认只校验，追加 --deliver 才重新生成并检查；node maintenance/refresh-contracts.mjs 同步台账，node maintenance/static-check.mjs 复查静态逻辑。ARCHIFY_CLI 可指定工具路径。修订后的 source JSON 是图形权威输入。

最终修改任何 JSON 后必须重新验证和交付，不应直接修改可信 HTML 的 SVG 或运行时。
